# Submission route recommendation

**Primary venue: TAISAP**

**Fallback venue: Wiley Security and Privacy**

TAISAP is the best semantic fit because the paper's object is the security of an
AI-serving environment and its method is both technical and economic. The recommendation
is conditional, not a claim of acceptance likelihood. The manuscript must present a
single systems-security contribution and stop suggesting primitive novelty.

Wiley Security and Privacy is the fallback because its official scope explicitly accepts
cloud/information security, applied case studies, testbeds, simulation studies, and
theoretical work. Its single-anonymous process would also eliminate the present conflict
between public artifact provenance and double-anonymous review, although it requires a
new package and possibly optional open-access cost decisions.

## Switch conditions

- **Switch condition 1:** If TAISAP confirms that public artifact/Zenodo links cannot be
  redacted during double-anonymous review, switch to Wiley rather than withdrawing the
  artifact or disguising its provenance.
- **Switch condition 2:** If the decisive extension fails the core lifecycle prediction,
  stop and revise the scientific claim before targeting any venue.
- **Switch condition 3:** If the extension produces a general result across independent
  implementations plus a defensible refinement link, reconsider TOPS as primary.
- **Switch condition 4:** If TAISAP rejects on AI-specificity but not validity, use Wiley;
  use IJIS only if a security editor requests a conventional implementation-focused
  treatment and the Springer reformatting cost is justified.
- **Switch condition 5:** If any prior submission remains active, submit nowhere until the
  author resolves exclusivity.

No submission, editor contact, publication, push, or archive update is authorized by this
recommendation.
